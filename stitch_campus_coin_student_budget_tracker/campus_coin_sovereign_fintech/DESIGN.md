## Brand & Style

This design system establishes a high-trust, institutional, yet youthful collegiate fintech identity. It merges the gravitas of a tier-one investment terminal with the kinetic clarity of modern student-centric digital finance.

### Design Movements & Visual Language
The visual approach blends **Precision Dark-Mode Modernism** with **Luminescent Accent Glassmorphism**:
- **Controlled Radiance**: Ambient emerald glows illuminate critical transactional touchpoints, ledger updates, and status signifiers without inducing visual fatigue.
- **Structural Integrity**: Strict 4px/8px metric rhythm aligned with modern CSS container standards and Bootstrap 5 variable hooks.
- **Architectural Depth**: Translucent slate overlays create multi-tier analytical elevation, eliminating flat visual monotony through rich dark surfaces.

### Emotional Target
The interface projects stability, cryptographic reliability, institutional security, and effortless transactional momentum.

## Colors

The palette pairs high-contrast emerald energy against deep, blue-shifted midnight slate foundations.

### Palette Architecture
- **Canvas Base (`#0a0f1d`)**: Deep midnight slate base layer for root bodies and viewport backdrops.
- **Surface Elevation 1 (`#111827`)**: Standard card, modal, and panel background.
- **Surface Elevation 2 (`#1f2937`)**: Interactive table rows, hover targets, and nested containers.
- **Primary Accent (`#10b981`)**: Interactive states, badges, positive balances, primary buttons, and key directional actions.
- **Primary Deep / Pressed (`#059669`)**: Hover/active states for primary actions, subtle glow outlines, and border highlights.
- **Tertiary Accent (`#38bdf8`)**: Protocol tags, campus node linkages, informative indicators, and cross-chain or multi-campus indicators.
- **Borders & Dividers (`rgba(255, 255, 255, 0.08)`)**: High-precision hairline borders defining components without visual friction.
- **Text Tiers**:
  - `Text-Primary`: `#f9fafb` (98% luminance contrast on slate).
  - `Text-Secondary`: `#9ca3af` (Financial meta-labels, sub-headers).
  - `Text-Tertiary`: `#6b7280` (Timestamps, disabled inputs, structural units).

### Glow Tokens
- `glow-emerald`: `0 0 24px -4px rgba(16, 185, 129, 0.35)`
- `glow-emerald-subtle`: `0 0 16px -2px rgba(16, 185, 129, 0.15)`

## Typography

The typographic hierarchy differentiates brand authority from transactional precision:
- **Headlines (Plus Jakarta Sans)**: Delivers sculpted geometric curves with high corporate weight, balancing fintech stature with student accessibility.
- **Body & Controls (Inter)**: Delivers maximum clarity at low display sizes, tabular alignment, and clean screen rendering.
- **Financial Balances & Node Identifiers (JetBrains Mono)**: Applied for all token metrics, wallet strings, transaction hashes, and quantitative tables to ensure tabular numeral alignment.

## Layout & Spacing

The layout is built upon a standard 12-column grid system fully aligned with Bootstrap 5 container specifications (`container-fluid`, `col-12`, `col-lg-8`, etc.).

### Layout System
- **Grid Configuration**: 12 columns with a fixed maximum inner content width of `1280px` on desktop viewports.
- **Breakpoints**:
  - `xs`: 0px–575px (Single column stacked, zero lateral outer gutter margins)
  - `sm`: 576px–767px (2-column cards, 16px lateral padding)
  - `md`: 768px–991px (Split ledger / wallet layout)
  - `lg`: 992px–1199px (Standard 12-column dashboard layout)
  - `xl`: 1200px+ (Extended analytics / multi-rail balance monitors)

### Spatial Hygiene
Component spacing follows an 8pt metric scale. Data tables, transaction histories, and form stacks prioritize strict 8px/16px/24px step intervals to maintain visual order across data-dense views.

## Elevation & Depth

Visual hierarchy uses tonal surface layering combined with emerald-tinted diffused drop shadows and hairline glass borders.

### Elevation Architecture
1. **Level 0 (Canvas Base)**: `#0a0f1d` with a radial gradient top-layer: `radial-gradient(ellipse at top right, rgba(16, 185, 129, 0.06), transparent 70%)`.
2. **Level 1 (Structural Cards)**: `#111827` overlaid with `border: 1px solid rgba(255, 255, 255, 0.08)` and `box-shadow: 0 4px 20px -2px rgba(0, 0, 0, 0.5)`.
3. **Level 2 (Active/Hover Cards)**: `#161f30` with `border-color: rgba(16, 185, 129, 0.3)` and `box-shadow: 0 8px 30px -4px rgba(0, 0, 0, 0.6), 0 0 16px -2px rgba(16, 185, 129, 0.12)`.
4. **Level 3 (Modals, Slide-outs & Overlay Flyouts)**: `#1e293b` backed by `backdrop-filter: blur(16px)` and a drop-shadow of `0 20px 40px -8px rgba(0, 0, 0, 0.8)`.

### Ambient Glows & Animation Rules
- **Luminescent Pulsing**: Key action zones (e.g., "Confirm Transfer") feature a subtle, infinite 3-second cycle on hover:
  ```css
  box-shadow: 0 0 0 0 rgba(16, 185, 129, 0.4);
  /* animating to */
  box-shadow: 0 0 20px 4px rgba(16, 185, 129, 0);
  ```
- **Transitions**: Standard easing curve for all interactive states: `cubic-bezier(0.16, 1, 0.3, 1)` across a `180ms` to `240ms` duration.

## Shapes

The interface balances sharp precision with modern ergonomics:
- **Containers & Cards**: Base border-radius of `0.5rem` (8px), scaling to `1rem` (16px) on primary wallet overview modules.
- **Interactive Controls (Inputs, Buttons, Dropdowns)**: Unified at `0.5rem` (8px) to align with standard Bootstrap form components.
- **Pills & Badges**: Fully rounded (`9999px`) for token tickers, KYC flags, transaction statuses, and campus nodes.
- **Hairlines**: Consistent `1px` border thickness across all non-card boundary elements.

## Components

### Buttons
- **Primary Action**: Gradient background `linear-gradient(135deg, #10b981 0%, #059669 100%)`, text `#ffffff` (`font-weight: 600`), hairline outline `rgba(255, 255, 255, 0.15)`. Hover generates `box-shadow: 0 0 20px rgba(16, 185, 129, 0.45)`.
- **Secondary (Outline)**: Background transparent, border `1px solid rgba(16, 185, 129, 0.4)`, text `#10b981`. Hover switches background to `rgba(16, 185, 129, 0.08)` and border to `#10b981`.
- **Ghost/Tertiary**: Background transparent, text `#9ca3af`. Hover transitions to `#f9fafb` with background `rgba(255, 255, 255, 0.04)`.

### Input Fields & Controls
- **Standard Input**: Background `#111827`, border `1px solid rgba(255, 255, 255, 0.12)`, text `#f9fafb`, placeholder `#4b5563`.
- **Focus State**: Border color `#10b981`, ring `box-shadow: 0 0 0 3px rgba(16, 185, 129, 0.2)`. Transition time: `150ms ease-out`.
- **Currency Entry Inputs**: Numerical entry formatted via `JetBrains Mono` at `24px` size, displaying trailing token affix ("CAMPUS") in `Text-Secondary`.

### Cards & Ledger Tables
- **Cards**: Surface color `#111827`, padding `space-lg`, border `1px solid rgba(255, 255, 255, 0.06)`. Subtle top-border highlight using a pseudo-element: `1px solid rgba(16, 185, 129, 0.2)`.
- **Data Tables**: Table header in `label-caps` typography, background `#0d1322`. Rows separated by `rgba(255, 255, 255, 0.04)`. Hover on row triggers `#141d30` with an animated `2px` emerald accent on the leftmost cell border.

### Status Indicators & Chips
- **Success / Confirmed**: Background `rgba(16, 185, 129, 0.12)`, text `#34d399`, border `1px solid rgba(16, 185, 129, 0.3)`.
- **Pending / In-Mempool**: Background `rgba(245, 158, 11, 0.12)`, text `#fbbf24`, border `1px solid rgba(245, 158, 11, 0.3)`.
- **Failed / Flagged**: Background `rgba(239, 68, 68, 0.12)`, text `#f87171`, border `1px solid rgba(239, 68, 68, 0.3)`.
- **Pills**: Compact height of `24px`, horizontal padding `8px`, using `JetBrains Mono` at `11px`.

### Custom Fintech Components
- **Campus Node Beacon**: A dual-ring indicator displaying connection to the university validator. Outer ring pulses continuously with an emerald radar animation (`scale(1.4)`, `opacity: 0`).
- **Cryptographic Hash Truncation Card**: Displays truncated student ID / public key with an interactive one-click copy feedback indicator that pulses green upon activation.
