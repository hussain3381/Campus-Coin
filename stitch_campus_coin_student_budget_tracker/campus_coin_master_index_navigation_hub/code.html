React 18 SPA + Inertia.js with Tailwind styling. Renders 390px mobile thumb-zone layout and desktop 12-column dashboards.

• React Inertia Pages • Heroicons / Material Symbols • ChartJS / Canvas Sparklines

3. Relational Persistence

ACID transactional storage with foreign key constraints, polymorphic ledger entries, and nullable user references for global defaults.

Schema::create('categories', function (Blueprint $table) {
    $table->id();
    $table->foreignId('user_id')->nullable()->constrained()->onDelete('cascade'); // NULL = System Default
    $table->string('name');
    $table->string('icon')->default('payments');
    $table->string('color')->default('#10b981');
    $table->decimal('monthly_limit', 10, 2)->nullable();
    $table->boolean('is_active')->default(true);
    $table->timestamps();
});
