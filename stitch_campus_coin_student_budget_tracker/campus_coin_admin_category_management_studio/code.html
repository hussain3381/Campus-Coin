Data Architecture Policy

Laravel 11.x

Master envelopes are stored in the core categories registry with an orphaned state:

database/migrations/create_categories_table.php content_copy 
Schema::table('categories', function (Blueprint $table) {
    // Global defaults have NULL user_id
    $table->foreignId('user_id')
          ->nullable()
          ->constrained()
          ->nullOnDelete();
          
    $table->boolean('is_system_mandatory')
          ->default(false);
          
    $table->decimal('suggested_spend_cap', 8, 2);
});
